# 授权组与工具参数规则

授权组决定客户端可以在哪些账号上使用哪些工具。本文给出模型与参数规则的完整定义；创建与操作步骤见 [用户指南](../USER_GUIDE.md)，安全边界见 [安全说明](../SECURITY.md)。

## 授权组模型

1. 创建具名授权组，可暂不关联任何对象。
2. 关联多个客户端和多个资产账号；组内每个客户端获得组内每个账号上被选中的、实际存在的工具权限。
3. 不同组允许重复关联相同客户端和账号；工具权限取启用组并集，同一个账号上的同一工具不会重复发布或调用。参数白名单按完整组条件取并集，任一适用组的黑名单优先拒绝。
4. 禁用/删除组会移除该组授权和参数限制，移除黑名单可能放宽其他组的调用权限。资产、账号或客户端禁用仍会阻断访问。
5. 上游 MCP 工具描述或 schema 变化后，旧版本批准失效；需在控制台重新查看并确认。授权组改名不意味着批准新工具定义。

每组最多 50 个客户端、50 个账号和 200 个工具。界面使用对象名称，API 和 MCP 协议仍保留稳定标识；不要把界面显示名称直接当作协议参数。

## 工具参数黑白名单

在授权组中添加账号、打开“配置工具”、勾选工具后展开“参数黑白名单”。未配置规则不增加限制；配置仅约束所选账号的该工具，不影响其它账号。支持顶层参数，单参数最多 50 条白名单和 50 条黑名单，每账号条目合计最多 200 条。

- 同参数多条匹配取 OR；同组多个参数的白名单取 AND；跨组必须满足至少一个组的完整白名单条件，任一适用组黑名单命中均拒绝。
- `exact` 精确匹配原文；`regex` 正则全文匹配（不是包含匹配），保留空白。正则最长 4096 字符，整次规则判定共享 100ms 匹配预算，超时拒绝。
- 字符串直接填写；数组、对象等按无空格 JSON 匹配（对象键排序），例如 `command` 为 `["uname","-a"]`。省略参数时使用 schema 默认值并显式传给执行器；无默认值时白名单不匹配，黑名单要求显式提供参数。
- API 格式：`entries[].parameter_rules = {"exec_command":{"cmd":{"allow":[{"match":"regex","value":"uname( -a)?"}],"deny":[{"match":"exact","value":"uname -a"}]}}}`。更新未传规则时保留原规则；显式 `{}` 清空，取消工具授权会移除其规则。
- 黑白名单不是 shell 沙箱。SSH 会将 `cmd` 原文交给远端 shell；未配规则时可执行任意非交互命令。建议使用精确白名单及远端最小权限账号，不要仅靠危险词黑名单保护系统。
